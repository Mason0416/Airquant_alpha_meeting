# 實驗報告

## 第一章：Baseline（基準模型）

實驗設定： 最基礎的動態報價，沒有庫存控制，每次成交成本扣 1 點。

實驗結果：  
總損益(PnL): -125984.39  
最大回撤 (MDD): -132347.62  
Sharpe Ratio: -2.42  
Sortino Ratio: -3.02  

實驗分析： 
1.  交易頻率過高： 報價太窄，導致被無效來回刷洗，手續費把本金吃光。
2.  逆向選擇風險 (Adverse Selection)：在面臨單邊趨勢行情時，策略會被動地與知情交易者成交，而累積大量虧損部位，進而產生巨大的帳面浮虧。

## 第二章：將半價差計算改為動態半價差

實驗設定：其他權重不變，只改半價差計算模式

實驗結果：  
總損益(PnL): -273236.33  
最大回撤 (MDD): -273663.75  
Sharpe Ratio: -5.20  
Sortino Ratio: -6.52  

實驗分析：因為台指期高頻跳動通常只有 1 點，所以算出來的 half_spread_proxy 大多是 0.5 點。但我們每次交易的手續費成本是 1.0 點！ 這導致策略報出低於手續費成本，每次成交都在倒貼給市場，引發毀滅性的交易成本耗損 (Transaction Cost Bleed)。

## 第一章與第二章心得

針對 V2 實驗中出現的負期望值問題，我回溯了初次面試時與學長討論到的『Pip 與 Tick 衝突』之觀念。

在台指期這類 Tick-constrained（受限於最小跳動單位）的市場中，當最小跳動單位（1 點）與交易成本（1 點）高度重疊時，若報價解析度過細（如 V2 算出的 0.5 點半價差），策略會因為無法覆蓋成本而陷入頻繁但無效的負預期交易。

因此，在 V3 架構中，我採納了當時討論的建議，將報價門檻強制提升至 1.5 個 Tick 以上，確保每筆成交在扣除成本後仍具備正向的 Expected Payoff。

## 第三章：設定一個base的最低底線(floor)

實驗設定：用clip函式將floor設定在1.5

實驗結果：  
總損益(PnL): -141314.05  
最大回撤 (MDD): -143812.71  
Sharpe Ratio: -2.69  
Sortino Ratio: -3.39  

死亡分析：雖然 V3 成功修復了 V2 的 Pip/Tick 衝突，將虧損從 -27 萬大幅收斂至 -14 萬，但其表現仍略遜於 V1 的固定 2 點模型。經分析，原因：獲利緩衝不足，1.5 點的底線在扣除 1 點交易成本後，僅餘 0.5 點利潤空間，在面臨 Adverse Selection 時，這 0.5 點難以覆蓋後續的價格滑價。

## 第四章：調高最低底線

實驗設定：將floor改到2.5

原因：因我發現在v1 時，我用固定 base 在 2 時的 -12萬高於v3的-14萬，因此我想提升floor

實驗結果：  
總損益(PnL): -39271.53  
最大回撤 (MDD): -61870.65  
Sharpe Ratio: -0.74  
Sortino Ratio: -1.03  

實驗檢討：
透過連續實驗，我發現台指期高頻造市的成功關鍵在於 Spread Buffer (利潤墊片)。當我將 Floor 從 1.5 提升至 2.5 後，PnL 從 -14 萬大幅收斂至 -3 萬。雖然最終結果仍為微負，但這已清楚定義了策略的邊際成本。

## 第五章：繼續調高最低底線

實驗設定：結合動態半價差與 2.5 點的 Floor 保護

實驗結果：  
總損益(PnL): 7571.59  
最大回撤 (MDD): -39809.45  
Sharpe Ratio: 0.13  
Sortino Ratio: 0.19  

核心洞察：
利潤空間的防禦性：Floor 設定在 2.5 點是此策略的轉折點。它確保了每筆交易在扣除成本後，仍有足夠的緩衝來應對逆向選擇。
動態過濾機制：雖然多數時間報價維持在 Floor，但這套機制有效地扮演了「噪音過濾器」。策略不再頻繁參與低期望值的交易，而是專注於捕捉高品質的成交機會。

結論：
透過對 Pip 與 Tick 衝突的修正，以及對獲利墊片（Buffer）的掌握，本策略已實現在台指期高頻環境下的初步獲利。這證明了在量化開發中，
**「理解市場微結構限制」與「合理的風控門檻」**
同樣重要。

## 未來優化路徑

導入 Inventory Skew（庫存偏移）：
目前的策略在面臨單邊趨勢時仍會累積滿手庫存。導入 Skew 機制能讓策略在累積多單時主動下調報價位階，雖然會增加平倉成本，但能大幅降低最大回撤（MDD）並提升資金利用率。
